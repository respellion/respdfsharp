# ResPdfSharp 7.0.0-preview-1-fork.1

First release of **ResPdfSharp** (Respellion Pdf Sharp) — an independent, MIT-licensed fork of [PDFsharp & MigraDoc](https://docs.pdfsharp.net).

## Why this fork

Upstream switched from the MIT license to a dual AGPL / commercial license with PDFsharp 6.5.0 (upstream commit `110751d`, 2026-10-14). ResPdfSharp is forked from `8d818d5` — the last upstream commit whose LICENSE file was MIT — and continues that line as a permissively licensed project. See [FORK.md](https://github.com/respellion/respdfsharp/blob/main/FORK.md) for the full provenance record and [NOTICE](https://github.com/respellion/respdfsharp/blob/main/NOTICE) for attribution and naming terms.

The baseline tag is [`fork-start`](https://github.com/respellion/respdfsharp/tree/fork-start) (= upstream `v7.0.0-preview-1`), and the untouched fork-start tree is archived byte-for-byte in the repo at `archive/respdfsharp-fork-start-8d818d5.tar.gz` (SHA-256 in the adjacent `.sha256` file).

## What's in this release

- Source state: upstream 7.0.0 Preview 1 (C# 12; targets net8.0, net9.0, net10.0, netstandard2.0; GDI/WPF variants also target net462).
- Published on NuGet: [`ResPdfSharp 7.0.0-preview-1-fork.1`](https://www.nuget.org/packages/ResPdfSharp/) — install with `dotnet add package ResPdfSharp --prerelease`.

## Changes vs upstream v7.0.0-preview-1

- Product renamed to **ResPdfSharp** / publisher **Respellion**; upstream logo/branding (README badges, NuGet package icons, marketing links) removed. "PDFsharp"/"MigraDoc" are used only attributively — this fork is not affiliated with or endorsed by empira Software GmbH.
- NuGet package ids renamed `PDFsharp*` → `ResPdfSharp*` (upstream `PDFsharp` stays the upstream package id).
- PDF `Producer`/`Creator` document strings and the digital-signature app name changed to ResPdfSharp, so PDFs generated by this fork are honestly attributed.
- Strong-name key replaced (forks may not use empira's signing key); `InternalsVisibleTo` tokens updated accordingly. Fork assemblies are strongly named and cannot be confused with upstream assemblies.
- License files: the original MIT notice is kept verbatim (required) with fork attribution added; new `NOTICE`, `FORK.md`, `CONTRIBUTING` documents provenance, upstream-import policy (post-fork upstream commits are AGPL and are not cherry-picked without MIT-compatible provenance), and the contribution license grant.
- Build: SDK pinned to stable 10.0.x via `global.json`; fixed NuGet nuspec property substitution (semicolons in copyright strings); fork copyright strings use a middot separator.

## Not changed (for API compatibility)

Namespaces (`PdfSharp.*`, `MigraDoc.*`) and assembly names are intentionally unchanged — migrating from upstream 6.2.4 / 7.0.0-preview-1 is a package-id swap, no code changes.
