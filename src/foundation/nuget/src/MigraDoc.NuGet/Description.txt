ResPdfSharp MigraDoc (fork of MigraDoc) is a .NET library that allows developers to create documents such as PDF and RTF using a high-level object model. It provides an intuitive API that simplifies the creation of documents, including text formatting, tables, images, and more. MigraDoc is widely used for generating reports, invoices, and other types of documents in various applications. Out of the box it embeds fallback fonts (Arimo, Tinos, Cousine under SIL OFL 1.1) so text rendering works on any platform, including Linux and containers without system fonts.

This package does not depend on Windows and can be used on any .NET compatible platform including Linux and macOS.

See https://github.com/respellion/respdfsharp for details.
