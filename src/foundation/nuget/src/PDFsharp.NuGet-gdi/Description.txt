ResPdfSharp (an MIT fork of PDFsharp) is the Open Source library for creating and modifying PDF documents using .NET. It has an easy-to-use API that allows developers to generate or modify PDF files programmatically. ResPdfSharp can be used for various applications, including creating reports, invoices, and other types of documents.

This package relies on Windows Forms (GDI+) and can be used under Windows only.

See https://github.com/respellion/respdfsharp for details.
